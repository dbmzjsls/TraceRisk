# 五分钟授信前调查合成演示

使用 [README](../README.md) 的 Mock/Fake 本地或 Docker 拓扑；当前运行结论见[验收入口](acceptance.md)。全部数据为合成数据。演示前检查 API 和 combined worker 健康，在 `/companies` 列表选择信用代码为 `SYNTHETIC-COMPANY-003` 的“远景精工（合成）有限公司”（稳定场景 `all-rules-95`；列表较长时可用浏览器页面查找），基准日期固定为 `2026-09-11`。使用独立演示库，不修改保留的 `tracerisk`。

| 时间 | 操作、可见状态和讲解 |
|---|---|
| 0:00–0:35 | 展示全局“合成数据，仅供演示”。说明面向金融机构的中小企业授信前调查；规则、证据、AI、人工和报告分开记录；分数只来自版本化规则，AI 不修改分值。 |
| 0:35–1:15 | 用 `analyst` 打开 `/companies/{company_id}`。展示信用代码、企业既有调查和基准日期表单，发起调查，跳转 `/investigations/{investigation_id}`。 |
| 1:15–2:10 | 等待 `awaiting_review`。左栏出现“等待人工复核”，右栏显示企业风险画像、四规则条件、覆盖警示、模型来源与复核原因，再查看原始 AI、覆盖与冲突、检索证据。点击引用定位冻结证据；说明系统校验引用合法性，并用 `claim_code` 对照结构化事实，不是万能事实核验。缺证据和零分不等于安全。 |
| 2:10–3:15 | 指出开放自然语言无法确定时显示 `indeterminate`，并进入人工复核。退出后用 `reviewer` 进入 `/reviews`，选择该调查的待复核发现。`/reviews/{finding_id}` 展示原始 AI。选择“修改（modify）”，改标题/摘要/推理并填写理由。结构与引用只读，提交保存独立人工版本。通过剩余发现；创建者不可自审。 |
| 3:15–4:15 | 回到调查，等待 `completed`。时间线显示“复核完成，等待恢复执行”和“调查完成，风险报告已生成”。进入不可变报告：最终发现含人工来源，原 AI 和人工决定仍可追溯，规则分数保持 95。 |
| 4:15–5:00 | 打开架构图和评测。解释 Outbox、持久 checkpoint、幂等复核/报告和 SSE 恢复。区分 Mock 八路径、真实模型生产流程与20例挑战结果；挑战复测仍有3例硬拒绝，不宣称全部正确。 |
