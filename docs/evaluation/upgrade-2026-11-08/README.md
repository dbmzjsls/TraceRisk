# 授信前调查改造实施记录

日期：2026-11-08。依据[项目改造计划书](../../项目改造计划书.md)执行。本页记录本轮修改和实测，历史 Stage 6 验收仍保留。

## 已实施内容

- **P0**：README、登录与工作区统一为“面向金融机构的中小企业授信前调查”。不新增授信额度、贷款审批或违约概率预测。
- **P1**：企业页按企业标识展示既有调查；调查详情和报告增加统一风险画像，包含四条规则条件、命中、等级、分数上限、覆盖警示。缺事实不按负面命中，零分不表示安全。证据引用仍使用既有定位功能。
- **P1**：后端返回权威复核原因和实际保存的模型来源。新报告快照保存基准日、企业代码、模型来源、证据来源地址和标题；已保存的观察日期继续展示。未存储的取得时间不伪造。旧报告不回写，模型来源缺失时明确标注未记录。
- **P2**：移除挑战评测中“出现事实键即可放行”的逻辑，复用生产保守复核；有效空发现仍检查输入证据冲突，转运行级复核。引用和声明支持性硬错误仍优先拒绝。
- **P2**：真实生产链路首次失败后，发现生产提示缺少允许的 `claim_code` 目录，而且模型上下文没有来源类型。补齐目录及来源类型，提示版本为 `risk-evidence-v2`。校验边界未放宽，没有 Mock 回退。
- **P2**：失败状态持久化安全分类，界面显示模型生成、引用/声明、检索完整性或结构失败及重新调查入口；不展示供应商响应正文或凭据。
- **P3**：保留原场景和日期，完成八路径浏览器验证，保存四张本轮截图及[五分钟配音截图讲解](TraceRisk五分钟讲解.mp4)。讲解采用 Windows 中文合成语音，画面为实际页面截图，不冒充五分钟实时操作录像。

沿用现有框架与数据库结构，没有增加依赖、迁移、评分权重或新仪表盘。代价是对自然语言扩展采取保守复核，会增加复核负担。

## 真实模型实测

### 生产 API → 队列 → 校验 → 复核 → 报告

[首次结果](real-workflow/result.json)：真实 `deepseek-flash` 返回结构化结果后，在引用/声明支持性硬校验失败，运行 `failed`、无报告，无静默模拟回退。

[修复生产提示后的结果](real-workflow-v2/result.json)：真实模型经生产 API 创建调查，由 combined worker 消费 Outbox/队列，冻结检索、计算95分、生成并校验发现、进入复核、通过公开复核接口提交决定、恢复流程并生成[不可变报告快照](real-workflow-v2/report.json)。总流程21,297毫秒；模型调用9,375毫秒，输入2,667 token、输出1,833 token。

该流程的复核决定由自动化测试账号提交，只证明协议和流程可用，未测量真人判断质量或耗时。使用 Fake embedding 与合成证据；不能视为真实资料检索或金融风险效果验证。生产适配器未记录缓存拆分与供应商账单，因此此流程实际成本仍未测量。

两次运行使用各自新建、拥有明确所有权的 `tracerisk_eval_*`；结束均清理，保留库检查通过。报告副本保存在本目录，运行 URL 所依赖的临时库已删除。

## 复现与演示

所有命令从仓库根目录运行；输出必须为新路径，不覆盖本目录原始证据。真实调用只从私有 `.env` 读取密钥。

```powershell
$env:PYTHONPATH = 'apps/api/src;.'
apps/api/.venv/Scripts/python.exe scripts/validate_investigation_upgrade.py replay --output .cache/upgrade-replay-new
apps/api/.venv/Scripts/python.exe scripts/validate_investigation_upgrade.py live --output .cache/upgrade-live-new
apps/api/.venv/Scripts/python.exe scripts/validate_real_workflow.py --output .cache/upgrade-real-workflow-new
```

数据库检查沿用[隔离要求](../e2e-checklist.md)；Mock八路径使用既有Playwright套件和拥有记录的临时目标。Windows API仍使用Selector事件循环。真实链路脚本需要本机保留基线，不能直接用于没有该基线的全新安装。

现场按[五分钟操作脚本](../../demo-script.md)演示，备用[企业详情](images/company.png)、[风险画像](images/risk-profile.png)、[来源不足](images/missing-coverage.png)、[报告](images/report.png)。[配音讲解文字稿](讲解稿.md)可用于练习答辩。
