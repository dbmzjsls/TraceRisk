## 文件使用顺序

先看 [六页预览](preview.png)，或在浏览器打开 [预览页面](preview.html)。

1. [展示版六页文案](slide-copy.md)：精简文案与讲述词；`slides/`有六张完整16:9 PNG与SVG页面，可直接插入PPT。详细答辩说明见 [备查讲述词](detailed-speaker-notes.md)。
2. `figures/`：SVG矢量图，可插入PowerPoint后按需转换为形状；含映射分布、历史路由对比、挑战三分类矩阵、证据链和报告标注图。
3. `screenshots/`：原始页面PNG，保留合成和Mock标识。
4. `chart-data.csv`、`number-footnotes.csv`：制图原数及台账编号。多个图的数据集不同，不能相加计算总成功率。

## 口径与表述

可以说：“整理了4家金融机构10篇公告的55条真实证据记录”“历史相同响应回放中，应复核进入复核由1/10增至9/10，额外复核由0/30增至15/30”“已用合成证据完成真实模型生产流程验证”。

必须同时说：“55条是按案例保存的记录，存在复用，真实资料尚未合格入库”“这不是中小企业授信业务效果评测”“真实模型流程使用Fake embedding、自动化复核”“20例挑战仍有3例应复核被硬拒绝”“真人效率未测量”。

不要说：“95条真实资料已入库”“95分就是95%违约概率”“零分就是安全”“22/22语义全部正确”“应复核9/10说明模型准确率90%”“21秒等于真人调查耗时”“生产v2通过20例质量评测”。

真实资料入库受身份、时间和逐条事实核验阻塞；展示版以演示样例表达流程，不声称该批真实资料已完成接入。候选非金融企业只完成资料候选核对，未完成目标场景业务验证。
