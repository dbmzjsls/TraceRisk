本次交付把历史证据复算、设计假设和待运行案例分开记录。范围为授信前事实核查与调查辅助：输出规则命中、可定位证据、待核实事项与复核建议。规则分不表示贷款批准、额度或违约概率。目前没有用户访谈记录，以下四条均为团队设计假设，不能写成“用户调研已证实的痛点”。

## 三分类预期与实际

`accept`为可接受，`manual_review`为人工复核，`reject`为输出拒绝。挑战校验器在有效空发现时也返回reject，故不能把所有reject都解释为硬校验错误，更不能解释为拒绝贷款。应复核案例中reject的具体原因见逐例表。引用/支持硬错误优先拒绝，不因输入存在冲突而放宽。

| 运行 | 预期 | 实际accept | 实际manual_review | 实际reject |
|---|---|---:|---:|---:|
| 40例历史 | accept | 15 | 0 | 0 |
| 40例历史 | manual_review | 0 | 1 | 9 |
| 40例历史 | reject | 0 | 0 | 15 |
| 40例同响应最终回放 | accept | 0 | 15 | 0 |
| 40例同响应最终回放 | manual_review | 0 | 9 | 1 |
| 40例同响应最终回放 | reject | 0 | 0 | 15 |
| 20例最终挑战复测 | accept | 0 | 5 | 0 |
| 20例最终挑战复测 | manual_review | 0 | 2 | 3 |
| 20例最终挑战复测 | reject | 0 | 0 | 10 |

来源：[历史最终回放](../evaluation/upgrade-2026-11-08/replay-final/replay.json)、[20例逐案记录](../evaluation/upgrade-2026-11-08/independent-final-live/cases.jsonl)。这两组使用不同输入和提示，不能合并画成一个“总准确率”。

历史40例的未进入复核从9/10减为1/10，剩余`conflict-009`为support_error。改造前9例均为reject，其中8例最终为空发现、1例最终为支持性硬错误，没有accept；不能把9例全部称为硬拒绝。`conflict-010`的历次validation_errors含support_error，但最终已返回空发现，应按最终响应解释。新增15个保守复核说明成本：所有原先预期accept的15例均转复核，并没有增加直接可用报告。20例中`validation-source_conflict-01/-04/-05`为support_error；2/5是应复核召回，3/5是未达标签要求的硬拒绝，二者不能合成5/5成功，也不表示非法报告已被放行。

20例最终响应结构通过20/20、结构与引用边界通过20/20、支持性错误3/20；其中12/20为空发现。边界通过包含空集通过，不能写成“全部语义正确”或“风险无遗漏”。预期reject的10例均返回空发现，说明此次模型未生成可接受发现，不单独证明引用校验器成功拦截了10个非法引用。

## 冻结12例的使用规则

[frozen-cases.json](frozen-cases.json)每类2例：F01—F02明确事实，F03—F04跨企业干扰，F05—F06时间更新，F07—F08跨源冲突，F09—F10来源缺失，F11—F12错误引用。每例固定企业、D、可见输入、规则预期、路由层、允许/禁止声明；F11修改引用哈希、F12修改连续摘录，候选响应一并冻结。没有新增真实业务样本。

冻结文件SHA-256为`53f4960906cb10ac2a30a15dcdfb6a430cde430c0f50e86dd605a0a7c623fda2`，覆盖UTF-8文件原始字节。标签由单人整理，第二人核验尚未完成；选择时已看过历史输出，所以只能称开发复用展示集。该哈希固定未来运行的输入及标签，不能倒称历史运行前就已经冻结。

只将`visible_input`中的事实、覆盖和必要声明目录交给模型；预期结果、历史结果、支持/干扰金标、允许/禁止声明及案例映射不进入模型上下文。`candidate_response`仅用于离线引用校验。不同路由层分别验收：F01—F04/F07—F08为挑战发现层，F05—F06为最新状态有效报告层，F09—F10为生产来源覆盖层，F11—F12为引用校验层。缺来源的生产运行预期复核，不与挑战空发现reject口径混用。不同层次不计算统一准确率。

F01/F02的accept针对规范化、无扩展、支持充分的输出，实际若含开放自然语言扩展可保守复核；不能为改善标签命中率放宽检查。规则预期只是展示设计标签，挑战校验器不执行规则引擎。所有冻结案例本次实际路由均为null，历史参考另列，未冒充本次运行结果。
