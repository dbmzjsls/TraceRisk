# 调查助手本地实跑

三个提示词通过同一个 Chromium 页面依次发送。两次调查生成和三次问答解释均调用 `deepseek-flash`。数据为合成样例，检索使用 Fake embedding。三组回答均处于待人工复核。

| 01 综合调查 | 远景精工规则分 95，经营 25、司法 35、舆情 20、知识产权 15，五条引用 | [提示词](01/prompt.txt) | [响应](01/response.json) | [截图](01/screenshot.png) |
| 02 来源不足 | 海晟服务规则分 0，工商来源不可用，知识产权来源已过期，没有待审 AI 发现，需补查并复核 | [提示词](02/prompt.txt) | [响应](02/response.json) | [截图](02/screenshot.png) |
| 03 司法追问 | 复用 01 的调查和 Run，说明司法规则 35 分，引用一条司法证据 | [提示词](03/prompt.txt) | [响应](03/response.json) | [截图](03/screenshot.png) |

各目录同时保存实际发送的请求 JSON 和该次运行的上下文快照。[清单](manifest.json)记录代码版本、调查与 Run ID、模型模式、时间及文件 SHA-256。问题哈希、上下文哈希和引用均已与原始记录核对。首轮留档发现来源不足回答遗漏了“没有待审 AI 发现”，修复后重新完成三组取证。表中采用复跑记录。
