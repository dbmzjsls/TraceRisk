# 六页上屏文案与讲述词

## 1｜知识库里有什么

**上屏**

- 真实资料：4家金融机构，10篇公告，55条按案例保存的证据记录。
- 混合数据包：95条证据、31例案例，区分真实、合成与改编。
- 真实记录映射：18条结构可映射、34条上下文、3条不可映射；合格入库0条。
- 企业事实用于检索；规则保留代码配置；评测标签与期望值隔离。

**配图**：`figures/knowledge-mapping.svg`。数字卡不要把公告数、证据数、案例数相加。

**讲述**：我们先交代资料是什么，再交代系统用到了哪一步。55条真实记录来自金融机构公告，会在不同案例中重复使用，不能当55个独立事实。结构可映射也不代表已核实可导入。

**脚注**：E01/E02/E10；2026-11-08文件复点。金融机构技术验证集；真实资料未完成合格入库与索引，目标中小企业业务验证未完成。

## 2｜知识如何支持调查

**上屏**

原文及披露日 → 主体、案号与状态 → 带哈希的片段 → 企业/时间约束检索 → 引用支持校验 → 复核与报告。

- 合成证据：已完成真实模型生产流程验证，使用Fake embedding。
- 真实公告：完成文件盘点与接入预检；真实语义检索和报告闭环未完成。
- 先守住公开时间：事件日不能替代披露日，更不能倒填获取日。

**配图**：`figures/evidence-chain.svg`。

**讲述**：已保存的合成报告能从一条发现定位到片段、来源地址、内容哈希和规则。我们没有把这项流程能力写成真实资料已经接入；真实资料要先通过身份与时点核验。

**脚注**：E03/E05/E10；真实资料Recall@5、跨企业误召回和引用定位比例未测量。Fake回归不代表语义检索质量。

## 3｜从调查问题到分析流程

**上屏**

| 调查问题 | 处理机制 | 输出 |
|---|---|---|
| 资料分散 | 统一来源及片段标识 | 可定位证据 |
| 同名、跨期混淆 | 企业ID与基准日约束 | 当前企业可见事实 |
| 生成缺少依据 | 冻结引用与支持校验 | 支持状态及拒绝原因 |
| 缺资料或冲突 | 覆盖警示与人工复核 | 待核实事项和下一步 |

**讲述**：任务是授信前事实核查和调查辅助。系统提供规则命中、证据与复核建议，最终判断由业务人员作出。四条关系是可检验的设计假设，尚不能称已经过用户访谈证实。

**脚注**：E03/E07；12例六类展示矩阵为开发复用/改编集、单人标签，生产v2新质量评测未运行。详见analysis-argument.md。

## 4｜用数据检验设计

**上屏**

- 历史40例相同响应回放：应复核进入复核 **1/10→9/10**。
- 代价：非应复核额外复核 **0/30→15/30**。
- 另20例挑战复测：应复核 **2/5进入复核、3/5硬拒绝**。
- 陈旧事实反例：旧open字段可匹配，但基准日声明仍可能错误。

**配图**：`figures/routing-before-after.svg`（主图）；`figures/challenge-routing-matrix.svg`（旁图，可作答辩备图）。

**讲述**：回放使用同一模型响应，证明的是校验和路由变化。对开放文本扩展采取保守处理减少漏复核，但增加工作量，且硬拒绝可能阻断调查。20例为另一套合成挑战提示，不能代表生产提示v2。

**脚注**：E04/E09；n=40回放与n=20挑战分别报告；标签未独立专家复查，结构和引用边界通过不等于语义正确。

## 5｜看懂一份调查结果

**上屏**

1. 分数：35+25+20+15=95，来自确定性规则。
2. 覆盖：来源域是否可用，与单条AI发现是否有充分支持分开判断。
3. 依据：引用片段、证据ID和哈希可追溯。
4. 复核：保留原AI、决定与最终报告版本。

**配图**：`figures/report-annotated.svg`，右侧说明与实际页面截图分区。

**讲述**：这里的页面来自Mock/Fake合成验收。另有真实deepseek-flash的生产流程快照：95分、五条发现支持状态为indeterminate，自动化提交复核后完成报告。不能用这张Mock截图冒充真实模型运行，也不能把95分解释为违约概率。

**脚注**：E05/E06；主体为远景精工（合成）有限公司，基准日2026-09-11。截图和真实模型快照是两次不同运行。

## 6｜不同结果如何行动

**上屏**

| 结果 | 应采取的行动 |
|---|---|
| 0分、来源不足 | 补资料、记录覆盖限制、运行级复核；零分不能证明安全 |
| 真实披露状态更新，离线35→0→0 | 核实二审和执行进展；规则归零不能证明债权已收回 |

已证明：引用与版本可查、来源不足可见、复核流程可执行。

未证明：真实中小企业业务效果、真人效率提升、行业准确率。

**配图**：`screenshots/missing-coverage-mock.png`；C案例按2026-01-06→06-16→07-10披露日画三点时间轴，备注“西安银行、金融机构、原告/申请执行人、离线解析”。

**讲述**：不同输出对应不同动作。零分时先看覆盖；状态改变时再看当事人地位和执行事实。自动化合成流程21.297秒只是一条流程记录，不能换算成人工节省比例。

**脚注**：E07/E08/E09；C三例均离线建议复核，执行状态未覆盖。真人任务时间、遗漏率及纠错时间未测量。
