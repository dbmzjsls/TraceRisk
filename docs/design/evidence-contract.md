# 证据、引用与支持性契约

依据：[实施计划](../../TraceRisk-v3-实施计划.md)第 11～13、15、17 节。

## 数据与读取边界

规则读取当前企业在调查基准日的结构化事实；AI 只读取本 Run 的 `retrieve_evidence` 选出的 Chunk。`prepare_context` 不向模型传递全部证据正文。

Evidence 归属一个企业，Chunk 归属一条 Evidence。企业历史名称和同名不能改变这一归属。Chunk 保存企业、来源、风险类型、时间、`fact_type`、`fact_value`、`polarity` 和内容哈希。结构化事件优先独立成片；新闻按自然段切分。

按司法、经营、新闻、知识产权分别检索，执行企业和权限过滤、去重、关键词与向量融合，并保存最终 `RetrievedEvidence`。传给模型的片段集合必须与保存的集合一致；不能在验证时扩大集合来接受模型编造的引用。

## 输出结构

每条 AIFinding 包含：

```text
finding_key
risk_type
claim_code
title
summary
reasoning
evidence_citations
evidence_sufficiency
confidence_level
```

每条 citation 包含：

```text
evidence_id
chunk_id
content_hash
quoted_excerpt
```

模型无风险分数字段或修改规则分数的权限。枚举具体值及 `claim_code` 对照表在对应业务规则实现前明确，不能接受任意字符串作为已获支持的结论。

## 内容哈希的技术约定

采用 SHA-256，对入库后最终 Chunk 正文的 UTF-8 字节计算，保存小写十六进制字符串。切片或换行规范化发生在计算前；引用校验对同一份存储正文计算，不临时 trim、替换空白或改写标点。

片段内容发生变化时不能沿用旧引用的内容版本；历史 Run 应仍能读取原片段内容或其快照。模型提交的哈希、RetrievedEvidence 所引用的版本及存储正文重新计算的哈希必须一致。哈希验证内容一致性，不证明来源事实真实。

`quoted_excerpt` 必须为非空、在该正文中连续存在的原文摘录，不能把模糊相似或改写当作精确引用。

## 硬校验与支持性校验

| 检查 | 拒绝情况 |
|---|---|
| 企业 | Evidence 不属于本次调查企业 |
| 证据与片段关系 | Chunk 不属于给定 Evidence |
| 检索范围 | Chunk 不在本 Run 已保存的检索集合 |
| 内容版本 | 任一哈希不一致 |
| 摘录 | 为空或不在片段正文中 |
| 权限 | 当前用户不可读取该证据 |
| 结构化支持 | claim_code 与 fact_type、fact_value 或 polarity 不一致 |

示例：合法 Chunk 说明案件已结案，模型却声称存在未结案件，即使 ID、哈希、摘录都合法也必须拒绝。未知 claim_code 不能默认获得支持。

无法确定的自由文本标记人工复核，不声称完成全文语义验证。进入复核不能让硬校验失败的引用成为合法引用；未通过的结论不得进入最终报告。具体校验错误到运行失败的错误分类由 AI 实现任务明确，结构化输出的两次总尝试上限不得被扩大。

人工修改后的候选结论执行相同校验，使用原 Run 的检索边界；校验失败不得提交该决定。AI 原始输出和人工修改分别保存。驳回保留理由和原始输出，不纳入最终结论。

## 来源覆盖和冲突

| SourceCoverage | 解释 | 报告与路由 |
|---|---|---|
| `available` 且没有相关记录 | 来源可查询，当前范围未发现该类记录 | 可描述“未发现”，不能泛化为绝对安全 |
| `unavailable` | 来源不可用 | 标记证据不足，强制人工复核 |
| `stale` | 超过允许时效 | 标记证据不足，强制人工复核 |

覆盖记录以调查基准日为准。各来源允许时效没有在原计划中给出，本阶段不虚构天数；合成数据可显式标记覆盖状态，自动计算阈值需在来源覆盖任务明确。

冲突要求同一企业、同一 `fact_key`、不同来源且规范化值互斥。两家同名企业不构成冲突；同一事实不同时期的正常状态变化不应误当成同一时点矛盾。保留双方证据，不加冲突分，强制复核；取舍计分见 [规则规格](rule-specification.md)的 D3 决策。

## 验收样例

合法同企业、同 Run、匹配内容与事实的引用应通过；分别替换企业、Evidence、Chunk、哈希、摘录、权限或事实方向应被拒绝。人工修改不得绕过其中任何一项。

零条检索结果不等于来源无风险，模型不得凭空补证据。零结论却需人工复核时，按已确认的 [D1](domain-model.md) 保存运行级决定，不伪造 AIFinding 或引用。证据中的提示词和 HTML 都是不可信内容：不能成为模型控制指令，HTML 报告展示时应转义，不能执行证据内脚本。
