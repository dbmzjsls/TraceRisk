# 确定性规则规格

依据：[实施计划](../../TraceRisk-v3-实施计划.md)第 10～11 节。规则编码、分数及去重键保持不变；时间端点、基准日有效状态与冲突优先级已按用户确认的 D3 补齐，并同步到原计划。

## 共同口径

所有规则相对于 `Investigation.as_of_date`（下称 D）运行，不使用执行时的系统日期替代基准日。仅评价当前企业的结构化事实；未来发生的事实不能倒灌到 D。

每个 Run 每条规则最多命中一次。多条案件或多项专利只扩充命中证据，不重复加分；重复执行受 `UNIQUE(run_id, rule_code)` 保护。快照保存规则编码、版本、参数（含基准日和时间口径）、分值、去重后事实及证据引用，以便复算。

## 四条规则

| 编码 | 冻结条件 | 去重键 | 单次分值 |
|---|---|---|---:|
| `JUDICIAL_OPEN_CASE_V1` | 至少一条 `status=open` 的案件 | `case_number` | 35 |
| `BUSINESS_ABNORMAL_V1` | 至少一条截至 D 仍有效的异常：已发生且 `resolved_at IS NULL` 或解除日期晚于 D | `abnormal_record_id` | 25 |
| `NEGATIVE_NEWS_V1` | D−364 至 D 至少两条独立负面报道 | `canonical_story_id` | 20 |
| `CORE_IP_ANOMALY_V1` | 核心专利失效或存在权属争议 | `ip_record_id` | 15 |

新闻的独立性按 `canonical_story_id` 判断，不按 URL、媒体数量或转载篇数判断。同一报道两次转载仍只是一条独立报道。知识产权规则评价核心专利；非核心专利不因该规则计分。

司法、经营、知识产权没有 365 天回看限制，判断 D 的有效状态；新闻才使用滚动时间窗口。缺少必要事实不能擅自当作明确负面证据。

## D3：已确认时间与冲突口径

新闻窗口为 `[D−364 天, D]`，包含基准日在内共 365 个自然日。若原始数据含时间戳，先按项目业务时区 Asia/Shanghai 转为日期；基准日之后的报道排除。

其他规则使用截至 D 已生效的状态。经营异常在 D 后才解除时，D 时仍未解除；D 当天解除则 D 不再命中。用户已确认使用基准日有效状态，取代只检查当前 resolved_at 是否为空的口径。实现可按 D 构造事实快照，也可写明有效区间，但必须得到相同业务结果。

冲突优先使用对应领域的来源：司法状态取司法来源、经营异常取工商来源、核心专利状态及权属取知识产权来源。无法确定可信优先级的冲突事实不贡献分数并标记证据不足；其他独立且无争议的命中仍可贡献分数。双方证据始终保留并强制复核，不允许模型决定分数。

上述来源优先级是本项目的合成演示约定，不是对现实机构的普遍可信度判断。互斥值、有效日期、核心标记等合成字段在数据实现前应映射为确定结构，不能由模型临时猜测。

## 总分与证据不足

总分为四条规则命中分值之和，真实满分 `35 + 25 + 20 + 15 = 95`，界面显示如 `60 / 95`。

| 分数 | 等级 |
|---|---|
| 0～29 | 低风险 |
| 30～59 | 中风险 |
| 60～95 | 高风险 |

模型和复核员不能输出、修改或重标定规则分数。证据冲突、来源不足不附加分数；规则零分且来源不足必须进入人工复核，并展示“证据不足”，不能写“无风险”。来源可用且没有命中才可陈述在本次范围内未发现规则风险。

## 规则验收样例

以下是经确认口径的规格样例，已人工走查，未运行代码测试。

| 输入 | 预期 |
|---|---|
| 两条不同案号均 open，同案号又重复一条 | 司法规则仅 35 分，保存去重后的相关证据 |
| 仅有 closed 案件 | 司法规则不命中 |
| 两条未解除经营异常 | 经营规则仅 25 分 |
| 同一 canonical_story_id 的两条负面转载 | 新闻规则不命中 |
| 窗口内两条独立负面报道 | 新闻规则 20 分 |
| 一条核心专利失效且另一条核心专利有权属争议 | 知识产权规则仅 15 分 |
| 仅有非核心专利异常 | 知识产权规则不命中 |
| 四条规则全部命中 | 95 分，高风险 |
| 司法加经营 | 60 分，高风险，需复核 |
| 仅司法且无任何其他复核原因 | 35 分，中风险，可直接报告 |
| 来源缺失，现有事实无命中 | 0 分、证据不足、强制复核 |
| D−364 的报道与 D 的另一独立报道 | D3：20 分 |
| D−365 的报道与 D 的另一独立报道 | D3：只剩一条，不命中 |
| D+1 解除的经营异常 | D3：D 当日仍计 25 分 |
| 同一事实的司法 open 与新闻 closed 冲突 | D3：按司法计分，保留两证据并复核 |

日期、冲突和窗口端点已获用户确认，后续规则实现应将这些样例转为回归测试；当前文档走查不代表实现测试通过。
